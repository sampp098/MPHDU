# MHDU
This repositoy provides the sources for Multi HD Units accelerator architecture
Here we provide:
1. The Architecture sources
2. The required C libraries
3. The Framework for programming HDC applications

## Architecture
To get the architectuer working in Vivado 2024.1
1. clone the repository in your local directory
2. Open Vivado
3. In vivado TCL console execute "cd ~your cloned repositoy"
4. source ./MPHDC/Make.tcl
